## URL Structure

**Prefix-based routing:**

```
/en/index.html          → English homepage
/sr/method.html         → Serbian method page
/fr/exams.html          → French exams page
/de/contact.html        → German contact page
... and so on
```

**All pages per locale:**
- `index.html` — Home
- `method.html` — Method
- `writing.html` — Writing
- `exams.html` — Platform exams
- `links.html` — Links
- `contact.html` — Contact

## Architecture

### Pure Static

All 300 pages are committed as static HTML files. **No generation step exists.**

To update translations:
1. Edit the HTML files directly in the locale directories (e.g., `en/index.html`, `sr/method.html`)
2. Maintain consistency: if you change structure, update all 50 locales manually or with find/replace scripts
3. Test locally with any static server: `python3 -m http.server 8080`
4. Commit and push

### Files

```
en/, sr/, fr/, ... (50 locale directories)
  index.html        → Home page
  method.html       → Method page
  writing.html      → Writing page
  exams.html        → Platform exams page
  links.html        → Links page
  contact.html      → Contact page
css/
  site.css          → Shared styles (one copy)
js/
  lang-switcher.js  → Interactive language picker
img/                → Shared images (one copy)
sitemap.xml         → 300 URLs with hreflang alternates
robots.txt          → Points to sitemap
index.html          → Root redirect to /en/
```

**No build process.** Edit HTML directly.

## Language Switcher

### Features

- **Interactive dropdown** in header on every page
- **Native language names** (e.g., Deutsch, 日本語, Srpski)
- **Preserves user preference** in localStorage
- **Links to same page** in other locale (e.g., `/en/method.html` switcher links to `/sr/method.html`, `/fr/method.html`, etc.)

### Implementation

- **HTML:** Generated by `build-i18n.mjs` (embedded in `<header>`)
- **CSS:** `.lang-switcher` styles in `css/site.css`
- **JS:** `js/lang-switcher.js` (dropdown toggle, localStorage, auto-redirect)

## SEO

### Complete SEO Implementation

Every page includes comprehensive SEO elements for Google indexing:

**1. Hreflang Tags**

All 50 locales plus `x-default` (pointing to English):

```html
<link rel="alternate" hreflang="x-default" href="https://www.admin.education/en/">
<link rel="alternate" hreflang="en" href="https://www.admin.education/en/">
<link rel="alternate" hreflang="sr" href="https://www.admin.education/sr/">
<link rel="alternate" hreflang="ar" href="https://www.admin.education/ar/">
... (all 50 locales)
```

**2. Canonical Tags**

Each page has its own canonical URL:

```html
<link rel="canonical" href="https://www.admin.education/en/method.html">
```

**3. Sitemap.xml**

300 URLs (50 locales × 6 pages) with 15,300 hreflang alternates (51 per URL).

Each URL entry includes:
- `<loc>` for the page URL
- 51 `<xhtml:link>` hreflang alternates (x-default + 50 locales)
- `<changefreq>` and `<priority>` metadata

**4. Robots.txt**

Points to sitemap and allows all locales:

```
Sitemap: https://www.admin.education/sitemap.xml
Allow: /en/
Allow: /ar/
... (all 50 locales)
```

**5. JSON-LD Structured Data**

Home pages include WebSite schema:

```json
{
  "@context": "https://schema.org",
  "@type": "WebSite",
  "name": "admin.education",
  "url": "https://www.admin.education/en/",
  "inLanguage": "en"
}
```

**6. HTML Lang & Dir Attributes**

Each page declares language and text direction:

```html
<html lang="en" dir="ltr">      <!-- English, left-to-right -->
<html lang="ar" dir="rtl">      <!-- Arabic, right-to-left -->
```

**7. Unique Meta Tags**

Every page has translated title and description in its locale.

## Editing Translations

**To update a translation:**

1. Navigate to the locale directory (e.g., `sr/` for Serbian)
2. Edit the HTML file directly (e.g., `sr/index.html`)
3. Maintain HTML structure, keep all tags and attributes
4. Update text content only
5. Test locally: `python3 -m http.server 8080`
6. Commit and push

**To add a new page or change structure:**

1. Edit the English version first (`en/pagename.html`)
2. Copy structure to all other 49 locales
3. Translate text content in each locale
4. Update sitemap.xml manually if adding new pages
5. Update navigation links in all locales

**No build step required.** All files are plain HTML.

## Deployment Notes

### GitHub Pages

The workflow publishes all 50 locale directories automatically. No extra config needed.

### Linode + Cloud Panel

Clone the repo and copy all files to `/home/admin/htdocs/www.admin.education`:

```bash
git clone https://github.com/ArhitektaHaosa/admin-education-site-staticv1.git
cd admin-education-site-staticv1
rsync -av --exclude='.git' ./ /home/admin/htdocs/www.admin.education/
```

**Optional nginx redirect (root to English):**

```nginx
location = / {
    return 302 /en/;
}
```

Or use Accept-Language header detection (requires extra nginx module).

## Technical Details

- **No React, no Vue, no framework:** Pure static HTML + CSS + minimal JS
- **No i18n libraries:** Translations are baked into committed HTML files
- **No Google Translate widget:** Professional translations committed to git
- **No SaaS (Crowdin, Lokalise, etc.):** Git-based manual workflow
- **RTL support:** Arabic (ar), Hebrew (he), Persian (fa), Urdu (ur) use `dir="rtl"`

## Browser Support

- **Language switcher:** Modern browsers (ES6+, localStorage)
- **Fallback:** Works without JS; links are plain `<a>` tags
- **Hreflang:** All search engines (Google, Bing, Yandex, Baidu)

## Performance

- **Shared assets:** `css/`, `img/`, `js/` are one copy for all locales
- **Gzip-friendly:** Repetitive HTML structure compresses well
- **Cache:** Long cache headers for `/css/`, `/img/`, `/js/` recommended
- **CDN-ready:** Static files can be served from edge
