# Multilingual Support (I18n)

## Overview

The site supports **16 languages** with URL-prefix routing. Each locale has 6 pages in its own directory.

**Version:** staticv1.6  
**Build date:** 2026-09-21

## URL Structure

**Prefix-based routing:**

```
/en/index.html          → English homepage
/sr/method.html         → Serbian method page
/fr/exams.html          → French exams page
/de/contact.html        → German contact page
... and so on
```

**All pages per locale:**
- `index.html` — Home
- `method.html` — Method
- `writing.html` — Writing
- `exams.html` — Platform exams
- `links.html` — Links
- `contact.html` — Contact

## Architecture

### Static Generation

All pages are pre-generated from JSON string catalogs. **No runtime translation or SaaS.**

### Files

```
locales/
  en.json           → English strings
  sr.json           → Serbian strings
  fr.json, de.json, ... → Other locales
scripts/
  build-i18n.mjs    → Generator script (Node.js)
en/, sr/, fr/, ...  → Generated locale directories
css/
  site.css          → Shared styles (one copy)
js/
  lang-switcher.js  → Interactive language picker
img/                → Shared images (one copy)
```

### Build Process

1. **Edit strings:** Modify `locales/{code}.json` files
2. **Run build:** `node scripts/build-i18n.mjs`
3. **Output:** 96 HTML files (6 pages × 16 locales)

## Language Switcher

### Features

- **Interactive dropdown** in header on every page
- **Native language names** (e.g., Deutsch, 日本語, Srpski)
- **Preserves user preference** in localStorage
- **Links to same page** in other locale (e.g., `/en/method.html` switcher links to `/sr/method.html`, `/fr/method.html`, etc.)

### Implementation

- **HTML:** Generated by `build-i18n.mjs` (embedded in `<header>`)
- **CSS:** `.lang-switcher` styles in `css/site.css`
- **JS:** `js/lang-switcher.js` (dropdown toggle, localStorage, auto-redirect)

## SEO

### Hreflang Tags

Every page includes `<link rel="alternate" hreflang="...">` tags for all 16 locales plus `x-default` (pointing to English).

Example from `/sr/index.html`:

```html
<link rel="alternate" hreflang="x-default" href="https://admin.education/en/">
<link rel="alternate" hreflang="en" href="https://admin.education/en/">
<link rel="alternate" hreflang="sr" href="https://admin.education/sr/">
<link rel="alternate" hreflang="fr" href="https://admin.education/fr/">
... (all 16 locales)
```

### HTML Lang Attribute

Each page has `<html lang="{code}">` for proper language declaration.

## Adding a New Language (17th+)

### Step 1: Create Locale File

Copy `locales/en.json` as a template:

```bash
cp locales/en.json locales/XX.json
```

### Step 2: Translate Strings

Edit `locales/XX.json`:

1. Change `"locale": "XX"` to your language code
2. Change `"lang_native"` to native language name (e.g., "Ελληνικά" for Greek)
3. Translate all strings under `site`, `nav`, `home`, `method`, `writing`, `exams`, `links`, `contact`
4. Keep HTML tags (`<a href="...">`, `<strong>`) intact
5. Keep product names (Unix, Nginx, PHP) unchanged

### Step 3: Update Build Script

Edit `scripts/build-i18n.mjs`:

```javascript
const LOCALES = ['en', 'sr', 'fr', ..., 'XX'];  // Add 'XX' to the array
```

### Step 4: Rebuild

```bash
node scripts/build-i18n.mjs
```

### Step 5: Deploy

Commit and push. The GitHub Actions workflow will publish the new locale.

## Deployment Notes

### GitHub Pages

The workflow publishes all locale directories automatically. No extra config needed.

### Linode + Cloud Panel

Upload all locale directories (`en/`, `sr/`, etc.) via SFTP or rsync.

**Optional nginx redirect (root to English):**

```nginx
location = / {
    return 302 /en/index.html;
}
```

Or use Accept-Language header detection (requires extra nginx module).

### Static Hosting (Vercel, Netlify, etc.)

Works out of the box. Optionally add redirects:

**Vercel `vercel.json`:**

```json
{
  "redirects": [
    { "source": "/", "destination": "/en/index.html", "statusCode": 302 }
  ]
}
```

**Netlify `_redirects`:**

```
/    /en/index.html    302
```

## Testing Locally

1. **Build:** `node scripts/build-i18n.mjs`
2. **Serve:** Use any static server:
   ```bash
   npx http-server -p 8080
   # or
   python3 -m http.server 8080
   ```
3. **Open:** http://localhost:8080/en/index.html
4. **Test switcher:** Click language dropdown, select another locale

## Maintenance

### Updating Exams

When `data/certs.json` changes (adding/editing platform exams):

```bash
node scripts/render-exams.mjs    # updates root exams.html (deprecated, kept for reference)
node scripts/build-i18n.mjs      # regenerates all 16 locale exams pages
```

### Updating Strings

1. Edit `locales/{code}.json` files
2. Run `node scripts/build-i18n.mjs`
3. Commit and push

### Consistency

Keep all locale JSON files in sync structurally. If you add a new key to `en.json`, add it (translated) to all other locales.

## Technical Details

- **No React, no Vue, no framework:** Pure static HTML + CSS + minimal JS
- **No i18n libraries:** Custom build script (220 lines of Node.js)
- **No Google Translate widget:** Pre-generated professional translations
- **No SaaS (Crowdin, Lokalise, etc.):** Git-based workflow
- **RTL not required:** None of the 16 locales use right-to-left script

## Browser Support

- **Language switcher:** Modern browsers (ES6+, localStorage)
- **Fallback:** Works without JS; links are plain `<a>` tags
- **Hreflang:** All search engines (Google, Bing, Yandex, Baidu)

## Performance

- **Shared assets:** `css/`, `img/`, `js/` are one copy for all locales
- **Gzip-friendly:** Repetitive HTML structure compresses well
- **Cache:** Long cache headers for `/css/`, `/img/`, `/js/` recommended
- **CDN-ready:** Static files can be served from edge
